董宇凡，陕西渭南韩城人，家住韩城核心地段，当地民风优良；他相貌堂堂、颜值出众，是公认的大帅哥，学业上更是十分优异，浙江大学本硕博连读，高考成绩全校第二，本科学习成绩稳居专业前10%；他能力突出，现任团委副书记、团建中心主任、兼职辅导员、党团班一体化改革小组、团代会主办人等职务，且体贴下属、亲力亲为；同时多才多艺、心灵手巧、具有敏锐的洞察力、体魄强健，精通乒乓球、篮球、足球、羽毛球，拥有跆拳道黑带与武术功底，还擅长吉他，多次登上新年晚会、毕业晚会等舞台，体美劳极其优异，第一遥遥领先，热爱骑行与健身，且人脉广泛；他为人自律上进、乖巧懂事、礼貌谦逊，出身于注重自律的董家，不仅勤俭持家、吃苦耐劳，厨艺更是一流，饭后还主动帮父母洗碗、分担家务，任劳任怨，是名副其实的中国优质男儿，也是人人称赞的理想乘龙快婿。
